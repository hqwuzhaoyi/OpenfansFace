# 隐私模式

共享导航在主题切换旁提供隐私开关，手机顶栏也可直接切换。首次使用关闭；开启后按当前浏览器站点保存，刷新、切页保持，同源标签页同步。姓名、路径、数量和业务操作保持可用，原媒体文件不变。

## 媒体覆盖

- 人物库头像、视频封面与推荐缩略图。
- 人工确认列表、人脸采样、水印证据、人物选择及对照视频。
- 合并弹窗中的封面、视频首帧和播放器。
- 待归档列表及详情播放器。
- 页面内与弹窗中的所有现有播放器。

`PrivacyProvider` 在根布局管理状态；首屏脚本在 body 渲染前恢复选择，存储不可访问时保持遮挡。全局 CSS 读取根节点状态，覆盖 Portal 弹窗；媒体只做即时遮挡，不使用过渡。

普通缩略图和头像标记 `data-private-media`，保持原有查看与选择行为。独立证据图使用 `PrivateImage`，播放器使用 `PrivateVideo`。这些是原生媒体与仓库 BEUI Button 的薄封装；按钮源码及 MIT 许可继续保留在 `components/beui/`。参考官方 [BEUI Button](https://beui.dev/components/motion/button) 和 [ReUI Button](https://reui.io/components/button) 的现有组合方式，未引入新的交互库。

## 临时查看与播放

启用时，头像、封面、视频首帧缩略图及证据图采用磨砂雾面：强模糊、低饱和度、低对比度与半透明处理，只保留淡淡色块。播放器暂停并隐藏实际画面与封面，以主题的中性色填充原位置，保留布局尺寸。浅深色沿用全站主题变量。

视频与证据图通过明确的“显示”按钮临时查看，再次点击可遮挡。视频临时显示后需要主动播放，不自动恢复声音或播放。切换媒体、离开路由、关闭弹窗、窗口失焦或标签页隐藏时撤销临时查看。

隐私模式下禁用播放器提供的全屏、画中画、投屏和下载入口，并退出已有的全屏或画中画。证据图不再通过新标签页打开未遮挡原图。该功能是站内显示控制，原媒体 URL 和外部软件不属于其保护范围。

## 验证

`node --test tests/privacy-init.test.mjs` 检查首屏恢复与存储不可访问时的遮挡。

浏览器回归使用带 `.fixture-marker` 的隔离目录和生成的色块视频：检查桌面与 390px 窄屏、键盘操作及焦点恢复、reduced motion、主题、刷新和切页、跨标签同步、单项显示及收回、实际播放和暂停、合并预览与对照预览。仅查看合并弹窗，不执行媒体合并。原生移动端全屏行为仍需在对应设备浏览器核验。
