# 处理操作台显示约定

遵循根目录 AGENTS.md：用布局、数量和状态表达工作，不叠加教学说明。沿用统一工作区、ReUI 搜索组合、BEUI 标签、现有 Progress 和全局主题。

| 区域 | 显示内容 |
| --- | --- |
| 页头 | 页面名称、暂停／恢复、刷新 |
| 当前任务 | 图标、任务标题、已用时间、文件名、实际阶段 |
| 阶段进度 | 已知总量时显示帧数和进度条；未知时保留实际阶段，不显示猜测百分比 |
| 下一步 | 一个「人工确认 + 数量」入口 |
| 阶段标签 | 全部、排队中、文字提取、人脸阶段、待确认、异常 |
| 任务列表 | 文件名、路径、阶段；正在处理项用主题状态色标记 |
| 详情与记录 | 沿用任务详情；运行记录和批次默认折叠 |

“人脸阶段”的数量包含等待人脸分析的任务，因此不用“正在分析”描述整个数量。顶部进度始终独立于列表筛选。

手机文件名最多两行，确认入口至少 44px 高。状态标题提供温和的辅助技术播报，耗时不触发反复播报。高频进度更新不加动画；断连保留上次阶段与进度，耗时按最后已知进展显示。

本次显示预览仅使用标注的演示数据，不连接正式媒体库。桌面、390px 手机、浅深色、键盘关闭后的焦点恢复、减少动效模式、未知进度／暂停／断连及演示视频播放均已检查。源码在共享工作区，由 UI 统一线程合并构建与发布。
