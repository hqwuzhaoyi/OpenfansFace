# 关联账号资料

人物详情页显示「女菩萨」公开 X 账号目录的匹配资料。在人物选择器中打开“看对照”，也可查看该人物的账号资料。紧凑人物选择器仅在打开弹窗后查询，避免一次请求全部人物。

## 匹配规则

- 已确认的 X 水印账号规则按完整账号匹配，忽略大小写，保留下划线与数字后缀。
- 人物名与账号字样一致但没有平台信息时，显示“待核对平台”。
- 人物名与外部昵称完全一致时，显示“同昵称 · 待核对”；重名记录全部保留。
- 组合人物名按空格、括号、竖线、逗号等明确分隔取名称片段，用完整片段匹配外部昵称或账号。例如 `HongKongDoll 玩偶姐姐` 可按昵称片段 `HongKongDoll` 找到 `@HongKong_Doll`，显示“名称片段一致 · 待核对”。不使用任意子串，也不删除账号下划线来凑匹配。
- Telegram、Instagram、OnlyFans 等平台不按同名映射到 X；来源规则不建立人物关联。
- 资料只供核对，不修改人物名、账号规则、视频归属或归档队列。

## 接口与缓存

`GET /api/persons/external?name=...` 查询人物；`GET /api/persons/external?token=...&platform=X` 查询水印账号（平台也支持 `unknown`）。

服务端读取 `https://img.boomboom.nyc.mn/data/archive.json`，在本地匹配，不向外站发送本地人物名、视频路径或截图。页面保留 `https://nv-pu-sa.pages.dev/` 来源链接、匹配依据、来源更新时间和缓存获取时间。

缓存位于 `FACES_BASE/external-profiles/nv-pu-sa.json`，有效期 24 小时，到期后下次访问时更新。并发请求合并；请求超时或数据无效时保留旧缓存并显示提示，失败后等待一分钟再重试。首次获取失败返回 503，不显示成“无匹配”。资料接口独立加载，不阻塞视频列表。

账号规则从已有的 `FACES_BASE/watermarks/mappings.json` 只读加载；没有水印功能或规则文件时仍可按人物名查询。
