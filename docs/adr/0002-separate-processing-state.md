# 分离任务状态、人脸特征与人工归名

自动分析使用独立的 `processing.db` 管理发现批次、阶段、重试、暂停和人工接管；新的人脸特征按文件指纹与版本缓存，不覆盖旧 `faces` 表，也不通过全库重建来处理单个视频。旧扫描的登记与分析耦合且缺少指纹，分离这些职责才能恢复中断任务、明确呈现失败，并让既有人工归名和归档逻辑继续运行。

媒体登记仅补充 `videos` 中不存在的记录，新记录用 `pipeline` 状态避免被旧的 `pending` 扫描循环重复领取。人物参考变化时重算匹配即可，模型或采样版本变化则重新评估缓存。代价是旧校准接口与新特征缓存并行存在，不能宣称它们是同一套完整数据或同一算法。

模型阶段在限时子进程中执行，同一时间只处理一个视频；阶段成功后提交状态，未检出是完成结果，技术失败最多自动重试两次。人工确认、备注和暂缓是独立的人工作业状态，确认后进入原待归档队列，自动分析不移动文件。
