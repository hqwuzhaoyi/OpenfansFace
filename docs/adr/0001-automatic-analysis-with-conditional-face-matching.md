# 自动启动分析，按需补充人脸证据

新视频发现后自动启动分析：先提取水印和文件夹等文字线索；水印命中已确认账号映射且无冲突时可进入人工确认，其余按需补充人脸分析。用户选择这一方式，以减少逐批启动的操作负担，并避免对已有明确线索的文件强制重复做人脸分析；自动分析产出候选，人物归属仍由人工确认。

这要求媒体发现、阶段执行与人工确认有明确边界，而不再依靠用户分别启动水印和人脸任务。后续确认了现有待分类存量也纳入、新视频优先、有效结果复用；仅文件夹或文件名命中姓名仍补做人脸。技术失败最多自动重试两次后交异常处理，未检出按正常分析结果进入人工核对；确认人物后仍保留独立的待归档步骤。

最后一轮已确认：每 5 分钟从媒体库增量发现，全天低并发运行并提供全局暂停；处理操作台管理任务，人工确认默认按候选人物分组，保留独立待归档。首版已实施，运行和存储边界见 ADR 0002。
